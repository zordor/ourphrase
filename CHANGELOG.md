# Changelog

All notable changes will be documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and releases use

## [Unreleased]

### Added

- Fully native SwiftUI application for iOS and iPadOS.
- Personal profiles and private per-person connection aliases.
- In-person QR and two-channel remote pairing.
- Rotating two-word verification phrases.
- Encrypted, portable backups and legacy PWA import.
- Public website, privacy policy and Universal Link fallback.

### Changed

- Project renamed from PassPhrase to OurPhrase.
- Public identity and links moved to `ourphrase.org`.
