# Contributing

Thank you for helping make identity checks understandable and accessible.

1. Discuss substantial changes in an issue before implementation.
2. Fork the repository and branch from `main`.
3. Keep changes focused and add tests for behavior changes.
4. Run `npm test` and the Xcode build documented in `ios/README.md`.
5. Open a pull request explaining motivation, security impact and testing.

Never include real invitation payloads, recovery phrases, personal names or
private infrastructure details in issues, fixtures or screenshots.

By contributing, you agree that your contribution is licensed under MPL-2.0
and that you have the right to submit it. Security-sensitive changes may
require additional review. Please follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
