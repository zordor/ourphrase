# Governance

OurPhrase is a maintainer-led community project.

- Maintainers set the roadmap, review changes and publish releases.
- Security, privacy and interoperability take precedence over feature speed.
- Significant protocol changes require an issue, documented rationale,
  compatibility analysis and tests.
- Maintainers may reject changes that weaken the threat model, introduce
  tracking, require unnecessary accounts or create avoidable network trust.
- Contributors who demonstrate sustained, constructive work may be invited as
  maintainers.

Project governance may evolve as the contributor community grows.
