Privacidad de OurPhrase

Última actualización: 29 de julio de 2026.

No recopilamos datos

OurPhrase no requiere cuenta, no contiene publicidad ni analítica y no envía conexiones, nombres, claves o palabras a ningún servidor.

Datos en tu dispositivo

Las claves se almacenan en el Keychain de Apple y los metadatos permanecen localmente. Las copias solo se crean cuando tú lo solicitas y están cifradas con tu frase de recuperación.

Enlaces de invitación

El secreto viaja en el fragmento del enlace, una parte que los navegadores no transmiten al servidor web. El PIN para conexiones remotas debe comunicarse por otro canal.

Permisos

  • Cámara: escanear códigos QR.
  • Face ID: bloquear la aplicación si decides activarlo.

Limitaciones

OurPhrase es una ayuda complementaria, no una prueba legal de identidad. Una coincidencia indica que ambos dispositivos poseen la misma clave compartida; no demuestra quién sostiene el teléfono. No debe utilizarse como único control para pagos, emergencias o decisiones críticas.

Software libre

El código fuente está disponible en GitHub bajo la licencia Mozilla Public License 2.0.
